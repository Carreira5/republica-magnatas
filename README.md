# República Magnatas - Site Institucional

Projeto de Desenvolvimento Web focado em Performance, Acessibilidade (WCAG 2.2) e Responsividade (Mobile-First).

## Desenvolvedores
* Filipe Bertucci Carreira

## Como executar o projeto localmente
1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no VS Code.
3. Utilize a extensão "Live Server" no arquivo `index.html` para abrir o site no navegador, ou use o link do netlify.

## Tecnologias Utilizadas
* HTML5 Semântico
* CSS3 (Flexbox/Grid, sem frameworks)
* Formato de imagens WebP, JPEG e JPG
